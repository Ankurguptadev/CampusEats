### 1. Invalid order: quantity is zero and address is missing — 422

$ curl -i -X POST http://localhost:8080/orders \
  -H 'Content-Type: application/json' \
  -d '{"items":[{"id":7,"qty":0}]}'

HTTP/1.1 422 UNPROCESSABLE ENTITY
Content-Type: application/problem+json; charset=utf-8
Content-Length: 221
Cache-Control: no-store

{"detail":"Correct the invalid fields","errors":[{"field":"items[0].qty","msg":"must be an integer >= 1"},{"field":"address","msg":"required"}],"status":422,"title":"Validation failed","type":"/errors/validation-failed"}


### 2. Create order — 201 with Location header

$ curl -i -X POST http://localhost:8080/orders \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -d '{"items":[{"id":7,"qty":2}],"address":"Hostel A"}'

HTTP/1.1 201 CREATED
Content-Type: application/json; charset=utf-8
Content-Length: 74
Location: /orders/2
Cache-Control: no-store

{"address":"Hostel A","id":2,"items":[{"id":7,"qty":2}],"status":"draft"}
